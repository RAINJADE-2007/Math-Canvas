# Math Canvas 数学画布

> 面向初中生、高中生与导数入门学习者的交互式数学学习网站 · 公益开源项目 · 非商业

一个集 **数学表达式输入、函数图像绘制、参数调节、基础计算、函数性质分析、导数可视化与分步解题** 于一体的交互式数学学习网站。

- 以中学数学为核心（约 80%）
- 适当加入导数入门作为连接高中函数与大学高等数学的拓展模块（约 20%）
- 无登录、无数据库、无支付、无广告，本地即可运行

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000 即可使用。

```bash
npm run lint      # 代码检查
npm run build     # 生产构建
npm run start     # 运行生产版本
```

## 功能总览

### 中学数学

- 函数画布：JSXGraph 交互式二维坐标系，支持拖拽、缩放、网格、坐标显示与多函数同屏；默认正方形画布（坐标轴单位长度一致、圆始终是圆），可按需切换 1:1 / 4:3 / 16:9 / 3:4 / 9:16 / 自适应长宽比
- 点选取：点击曲线即可选取并固定显示该点的坐标与函数值（含导数值），可拖动标记沿曲线移动、可移除与清空
- 图像平移：使用「平移图」工具直接拖动函数图象进行平移，自动生成平移后的解析式，可应用为新函数、复制或重置
- 表达式输入：支持 `x^2`、`y=x^2`、`f(x)=sin(x)` 等形式，math.js 解析，KaTeX 实时公式预览
- 间断点处理：`1/x`、`tan(x)`、`1/(x-2)`、`log(x)`、`sqrt(x)` 正确断开，不跨越垂直渐近线
- 参数滑块：自动识别 `a、b、c、k、A、w、p` 等参数，拖动滑块实时刷新图像与性质
- 函数性质分析：一次、二次、反比例、三角函数的性质自动提取
- 科学计算器：四则运算、乘方、根式、三角与反三角、指数、对数等
- 分步求解：一元一次方程、一元二次方程、一元一次不等式，含移项、合并、求根公式与代入验证
- 基础平面几何：点、直线、线段、圆，两点距离、中点、斜率、面积与周长；支持使用「点 / 线 / 圆」工具在画布上直接点击绘制（带实时预览，Esc 取消）；选中对象后可在画布上拖动整体平移并自动更新数据；直线与圆可自动呈现并修改对应方程
- 基础统计：数据个数、总和、平均数、中位数、众数、极差，柱状图与折线图

### 导数入门（拓展）

- 基础符号求导：常数、幂函数、常数倍、和与差、sin/cos/exp/log 等
- 数值导数：中心差分近似，复杂表达式自动降级并明确标注“数值近似”
- 切线动态展示：曲线上可拖动切点，切线方程实时更新
- 割线逼近切线：调节步长 h，观察割线斜率逼近导数值
- 原函数与导函数联合绘制：导函数以虚线绘制
- 单调性与极值：区间分析、临界点标记、极大值/极小值判断

### 系统能力

- 本地保存（localStorage）与 JSON 导出/导入
- 撤销与重做
- 错误边界：输入异常与渲染异常均不会导致页面崩溃
- 模块化学科架构：高等数学、线性代数、概率论、复变函数已预留扩展

## 技术栈

| 用途 | 技术 |
| --- | --- |
| 前端框架 | Next.js（App Router）· React · TypeScript |
| 样式 | Tailwind CSS |
| 坐标画布 | JSXGraph |
| 数学解析与计算 | math.js |
| 公式渲染 | KaTeX |
| 状态管理 | Zustand |
| 本地存储 | localStorage |

## 目录结构

```
src/
├─ app/                  # 页面（首页、画布、关于、学科模块）
├─ components/           # 画布、面板、组件
├─ math-engine/          # 数学引擎（与 React 完全解耦）
│  ├─ core/              # 解析、验证、求值、采样
│  ├─ middle-school/     # 函数分析、方程、不等式、几何、统计、分步求解
│  └─ calculus-intro/    # 求导、切线、割线、单调性、验证
├─ subjects/             # 学科模块接口、注册表与各学科模块
├─ store/                # Zustand 全局状态
├─ types/                # 共享类型
└─ constants/            # 常量
```

## 安全设计

- 禁止 `eval()` 与 `new Function()`
- math.js AST 校验：函数白名单、符号白名单、禁止赋值/对象访问/模块导入
- 所有计算均捕获异常，非有限值以 NaN 处理
- 表达式长度与数量限制

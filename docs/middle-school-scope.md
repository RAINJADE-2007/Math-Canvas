# 中学数学范围（初版）

## 目标

以中学数学为核心（约占整体功能 80%），覆盖函数、方程、不等式、几何与统计的基础内容。

## 正式支持

### 函数画布

- 一次、二次、反比例、幂、绝对值、三角、指数、对数函数；
- 支持 `x^2`、`y=x^2`、`f(x)=x^2`、`g(x)=sin(x)` 等输入形式；
- 多函数同屏、显示/隐藏、删除、编辑、改色；
- 正确绘制 `1/x`、`tan(x)`、`1/(x-2)`、`log(x)`、`sqrt(x)` 等存在间断点的函数。

### 表达式与参数

- 自动提取等号右侧表达式；
- 识别参数 `a、b、c、k、A、w、p`（共享同一参数值）；
- 参数滑块默认：最小值 -10、最大值 10、默认值 1、步长 0.1。

### 函数性质分析

| 函数类型 | 分析内容 |
| --- | --- |
| 一次函数 | 斜率、y 轴截距、与 x 轴交点、单调性 |
| 二次函数 | 系数 a/b/c、开口方向、对称轴、顶点、判别式、与 x/y 轴交点、最大/最小值 |
| 反比例函数 | 比例系数、所在象限、定义域、值域、渐近线 |
| 三角函数 | 振幅、周期、相位偏移、纵向偏移 |

无法完整识别时提示：`当前版本暂不支持该函数的完整性质分析。`

### 计算与求解

- 科学计算器：四则、乘方、括号、平方根、绝对值、三角与反三角、指数、对数、pi、e；
- 一元一次方程、一元二次方程、一元一次不等式：移项、合并同类项、系数化 1、求根公式/因式分解、代入验证；
- 不等式必须正确处理除以负数时不等号方向改变。

### 平面几何

- 点、直线（两点）、线段（两点）、圆（圆心+半径）；
- 两点距离、线段中点、直线斜率、直线方程、圆面积与周长；
- 对象显示/隐藏、删除。

### 基础统计

- 数据个数、总和、平均数、中位数、众数、最大值、最小值、极差；
- 柱状图、折线图、频数分布（轻量 SVG 实现）。

## 不实现

- 严格极限证明、完整极限运算、积分、微分方程、级数；
- 矩阵与线性变换、概率分布、贝叶斯公式、复数函数；
- AI 自动解题、图片识题、手写公式识别；
- 复杂分式不等式与高次不等式。

## 边界处理

- 表达式长度 ≤ 200，最多 20 个函数，最多 10 个参数；
- 非法输入显示提示且不会导致页面崩溃；
- 不支持的内容显示：`当前版本暂不支持该数学内容。`

# 答辩演示流程

建议按以下顺序演示，覆盖初版全部核心功能。全程使用桌面端浏览器，分辨率建议 1920×1080 或 1440×900。

## 开场（约 2 分钟）

1. 打开首页，介绍项目名称“Math Canvas 数学画布”；
2. 说明项目定位：公益、开源、非商业，面向中学生与导数入门学习者；
3. 强调核心理念：图像辅助理解、计算辅助验证、步骤辅助学习。

## 函数画布（约 4 分钟）

4. 点击「进入数学画布」；
5. 输入 `y=x^2`，展示抛物线；
6. 再输入 `y=sin(x)`，展示正弦曲线（多函数同屏）；
7. 修改函数颜色、隐藏与重新显示函数；
8. 输入 `y=1/x`，展示 x=0 处间断点不连接；
9. 输入 `y=tan(x)`，展示垂直渐近线正确处理。

## 参数动态探索（约 3 分钟）

10. 输入 `y=a*x+b`，出现 a、b 参数滑块；
11. 拖动滑块，图像实时变化；
12. 输入 `y=a*x^2+b*x+c`，设置 a=1、b=-4、c=3；
13. 选中该函数，属性面板展示对称轴、顶点、判别式与根。

## 计算与求解（约 3 分钟）

14. 计算器输入 `sin(pi/2)`，结果为 1；
15. 求解 `2*x+3=7`，展示移项、合并、系数化 1 的分步过程；
16. 求解 `x^2-5*x+6=0`，展示判别式与求根/因式分解；
17. 求解 `-2*x+4>0`，展示除以负数时不等号方向改变。

## 导数入门（约 5 分钟）

18. 对 `f(x)=x^2` 点击「显示导数」；
19. 展示导函数 `2*x`（紫色虚线）与求导分步；
20. 在曲线上拖动切点 P，切线方程实时更新（例如 a=2 时切线 `y=4x-4`）；
21. 调节割线步长 h，观察割线斜率逐渐逼近切线斜率；
22. 展示单调区间与极值点（x=0 处极小值）。

## 几何与统计（约 2 分钟）

23. 添加点 A(2,3)、点 B(6,5)，展示两点距离与中点；
24. 添加圆 O(0,0) 半径 3，展示面积与周长；
25. 输入数据 `12,15,15,18,20`，展示平均数、中位数、众数与统计图。

## 收尾（约 2 分钟）

26. 刷新页面，展示本地数据自动恢复；
27. 导出/导入 JSON 演示；
28. 打开学科模块页面，展示高等数学、线性代数、概率论、复变函数为「开发中」占位；
29. 总结创新点与后续规划，说明项目的模块化扩展能力。

## 答辩要点

- 强调：**不承诺解决所有数学问题**，而是通过交互式图形、计算验证与分步说明辅助理解；
- 强调模块化学科架构，后续可独立扩展大学数学模块；
- 强调安全设计（无 eval、白名单校验）与本地优先（无后端、无数据库）。

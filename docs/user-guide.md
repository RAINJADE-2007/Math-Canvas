## 一、快速上手

1. 在项目目录运行 `npm install` 与 `npm run dev`，浏览器打开 http://localhost:3000。
2. 在首页点击「**进入数学画布**」。
3. 在底部「**表达式**」面板输入 `x^2`，按回车键。
4. 一条抛物线立即出现在中央画布上。
5. 试着输入 `sin(x)`、`1/x`，观察多个函数同屏显示、间断点正确断开。

三步即可完成第一次绘图。

## 三、顶部导航与文档栏

### 3.1 顶部导航栏

- **Math Canvas 标志**：点击回到首页。
- 导航项：**首页 / 数学画布 / 学科模块 / 项目说明**。
- 「学科模块」页面中，**中学数学**与**导数入门**已开放，**高等数学、线性代数、概率论、复变函数**显示“开发中”占位（不提供虚假计算）。

### 3.2 文档栏（画布页顶部）

- **文档名称**：输入框可修改，用于本地保存与导出文件命名。
- **本地自动保存中**：绿色提示，表示内容已实时写入浏览器 localStorage，刷新页面不会丢失。
- **导出 JSON**：下载一份完整的文档备份（格式见第 15 节）。
- **导入 JSON**：选择之前导出的 `.json` 文件即可恢复，可用于课堂展示或换机迁移。

## 五、中央二维坐标画布

### 5.1 基础操作

| 操作 | 方法 |
| --- | --- |
| 平移视野（拖拽） | 点击左侧工具栏「**拖动**」工具后，按住鼠标左键拖动 |
| 缩放 | 使用画布右上角 ＋/− 按钮（鼠标滚轮用于调整画布比例，见 5.1.2） |
| 查看坐标 | 左上角实时显示鼠标位置 `x: …, y: …` |
| 选择函数 | 点击函数曲线，曲线高亮并在右侧显示性质分析 |
| 拖动切点 P | 在导数分析开启后，直接拖动曲线上的点 P（不会移动视野） |
| 重置视野 | 点击左侧工具栏「重置」 |

> 提示：**「选择」与「拖动」分工明确**——选择工具只用于选中对象，不会误移画布；拖动工具只用于平移画布，即使从几何图形上开始拖动也只会平移、不会误拖图形。可拖动的点（切点 P、已选取的点）始终可用选择工具直接拖动。

### 5.1.1 画布控制面板

画布右上角提供控制面板：

| 控件 | 功能 |
| --- | --- |
| ＋ | 放大（以画布中心为基准） |
| − | 缩小（以画布中心为基准） |
| 适配 | 自动适配：保持当前横坐标范围，自动调整纵坐标，使全部可见函数完整显示 |
| 1:1 | 一键将两坐标轴单位长度恢复为 1:1（正方形画布，高亮表示当前即为 1:1） |
| 比例 | 弹出「调整画布比例」面板，选择 1:1 / 4:3 / 16:9 / 3:4 / 9:16 / 自适应或拖动滑块自定义（Esc 或点遮罩关闭） |
| 百分比 | 当前缩放比例（默认 100%） |
| 坐标范围 | 实时显示当前视野 `x:[a, b]  y:[c, d]` |

初始坐标范围：x：−10 到 10，y：−10 到 10。

### 5.1.2 画布比例（长宽比）

- **默认正方形**：画布默认为 1:1 正方形，两坐标轴单位长度始终一致，**画出的圆始终是正圆**；
- 调整方式：
  - 画布右上角「**比例**」按钮 → 弹出调整面板（预设按钮 / 自定义滑块 / 设为 1:1）；
  - 右侧属性面板「画布设置 → 画布比例」（未选中对象时可见）；
  - **鼠标滚轮**：在画布上滚动滚轮直接调整宽:高比例（上滚增大、下滚减小）；
- 自定义滑块范围 0.25 ~ 4（宽:高）；
- 无论选择何种比例，坐标轴单位长度始终一致（圆永远是圆）；
- 比例按钮带**点击节流**（500ms 冷却），快速连点不会导致页面卡顿。

### 5.1.3 点的数据（悬停）

将鼠标移动到画布上，会在两处实时显示当前点的数据：

- **画布右下角**：显示当前点坐标 `P(x, y)`，以及每个可见函数在该点的取值（带各自颜色标记）；已开启导数分析的函数还会显示 `f'` 的取值；
- **右侧属性面板（函数属性的下方）**：选中某个函数后，在「点的数据」区域显示该函数在当前点的函数值与导数值。

> 示例：函数 `x²`，鼠标移到 (2, 3) 处，会显示 `P(2.000, 3.000)`、`x² = 4.000`，若已开启导数还会显示 `f' = 4.000`。

### 5.1.4 函数点选取（固定取点）

- **点击函数曲线**即可在该处固定选取一个点（标记为圆点，并带坐标标注）；
- 已选取的点会显示在画布右下角「已选取的点」列表中，呈现坐标、函数值，开启导数后还显示导数值；
- 拖动标记可沿曲线移动，点数据实时更新；
- 每个点可单独「×」移除，或一键「清空」；
- 选中某个函数时，右侧属性面板「已选取的点」区域也会同步展示该函数的所有取点；
- 点数据随文档保存；删除函数时其取点自动清理。

### 5.2 画布显示内容

- **坐标轴**：x 轴与 y 轴（灰色）。
- **网格**：浅灰色网格线。
- **函数曲线**：每条曲线使用独立颜色，右上角附近显示函数名称；被平移的函数显示「平移」徽标。
- **导函数**：开启导数分析后，导函数以**紫色虚线**绘制。
- **切线**：红色虚线。
- **割线**：橙色实线，端点为点 Q。
- **切点 P**：白色圆点，位于曲线上，可拖动。
- **临界点**：灰色“×”标记（极值点等）。

### 5.3 函数的间断点处理

画布会自动正确处理以下情况，不会把间断点两侧错误连接：

- 除零：`1/x`、`1/(x-2)`
- 正切函数：`tan(x)` 的垂直渐近线
- 负数开平方：`sqrt(x)` 在 x < 0 时无图像
- 对数定义域：`log(x)` 在 x ≤ 0 时无图像

## 六、右侧属性面板

### 6.1 未选择任何对象时 —— 画布设置

- **显示网格** / **显示坐标轴**：开关网格与坐标轴。
- **显示函数名称**：是否在曲线旁显示表达式。
- **显示单调性提示**：开启后，画布上会标注“递增/递减”箭头区间与临界点坐标。
- **画布比例**：预设按钮（1:1 / 4:3 / 16:9 / 3:4 / 9:16 / 自适应）、自定义滑块、「设为 1:1」按钮（详见 5.1.2）。

### 6.2 选中函数时 —— 函数属性与性质分析

点击画布上的曲线，或点击「表达式」列表中的条目，右侧面板会显示：

- 表达式（KaTeX 公式渲染）；
- 颜色选择器、显示/隐藏开关；
- **函数性质分析**（随参数实时更新）：
  - 一次函数：斜率、y 轴截距、与 x 轴交点、单调性、定义域；
  - 二次函数：系数 a/b/c、开口方向、对称轴、顶点、判别式、与 x/y 轴交点、最大/最小值；
  - 反比例函数：比例系数、所在象限、定义域、值域、渐近线；
  - 三角函数：振幅、周期、相位偏移、纵向偏移。

> 无法完整识别时会提示：`当前版本暂不支持该函数的完整性质分析。`

选中函数后，属性面板还会显示：

- **点的数据**：鼠标悬停在画布上时，实时显示该函数在当前点的函数值与导数值（见 5.1.3）；
- **已选取的点**：该函数上所有固定取点的坐标、函数值与导数值，可逐个移除（见 5.1.4）；
- **图像平移**：展示当前平移量（水平/垂直）与平移方向描述、平移后的解析式（KaTeX 预览 + `y = …` 文本），支持：
  - 「**应用为新函数**」：把平移后的解析式作为新函数添加到列表；
  - 「**复制解析式**」：复制到剪贴板；
  - 「重置」：取消平移；
  - 也支持在「水平 / 垂直」输入框中直接输入平移量。

### 6.3 选中几何对象时

显示对象名称与“显示/隐藏”开关，并支持：

- **平移**：使用左侧工具栏「平移」工具在画布上拖动该对象，整体平移后数据与方程自动更新；
- **方程**：直线与圆自动呈现对应方程（如 `y = 2x + 1`、`(x-1)^2+(y-2)^2=9`），可在输入框中修改并点「更新」应用；点对象显示坐标、不支持方程编辑。

## 七、底部面板 · 表达式

用于添加、管理函数。这是最常使用的面板。

### 7.1 添加函数

1. 在输入框中输入表达式，例如 `x^2`；
2. 按**回车键**，或点击「**添加函数**」按钮；
3. 输入时下方会实时显示 **KaTeX 公式预览**；
4. 添加成功后，函数出现在列表中并绘制到画布。

支持的输入形式（系统自动提取等号右侧表达式）：

```
x^2
y=x^2
f(x)=x^2
g(x)=sin(x)
2*x+1
```

常用函数写法：

| 类型 | 示例 |
| --- | --- |
| 一次函数 | `x`、`2*x+1`、`a*x+b` |
| 二次函数 | `x^2`、`x^2-4*x+3`、`a*x^2+b*x+c` |
| 反比例函数 | `1/x`、`k/x` |
| 幂函数 | `x^3`、`sqrt(x)` |
| 绝对值 | `abs(x)`、`abs(x-2)` |
| 三角函数 | `sin(x)`、`cos(x)`、`tan(x)` |
| 指数/对数 | `2^x`、`exp(x)`、`log(x)`、`log10(x)` |

支持的函数白名单：`sin cos tan asin acos atan sqrt abs log log10 exp floor ceil round`。
常数：`pi`（圆周率）、`e`（自然常数）。
允许隐式乘法：`2x` 等价于 `2*x`。

限制：

- 单个表达式最长 **200 个字符**；
- 最多添加 **20 个函数**；
- 非法输入会显示红色提示，**不会导致页面崩溃**。

### 7.2 函数列表操作

每个函数条目提供：

| 控件 | 功能 |
| --- | --- |
| 颜色圆点 | 标记该函数颜色 |
| 类型徽标 | 一次/二次/反比例/三角函数等 |
| 「导数」徽标 | 已开启导数分析时显示 |
| 「平移」徽标 | 已平移（图像被移动过）的函数显示 |
| 隐藏 / 显示 | 在画布上隐藏或重新显示该函数 |
| 编辑 | 进入行内编辑，修改后按回车保存，Esc 取消 |
| 删除 | 从画布与列表移除 |
| 颜色选择器 | 修改函数颜色 |
| 分析函数 | 选中并在右侧查看性质分析 |
| 显示导数 / 隐藏导数 | 开启/关闭该函数的导数分析（见第 13 节） |

> 注意：在「表达式」面板输入 `2*x+3=7` 会被解析为等号右侧的函数 `y=7`（画一条水平线）。**解方程请使用「方程求解」面板。**

## 八、底部面板 · 参数

当函数中含有 `a、b、c、k、A、w、p` 等参数时，会自动生成滑块。

### 8.1 识别参数

- 例如输入 `a*x+b`、`a*x^2+b*x+c`、`k/x`、`A*sin(w*x+p)`，参数面板自动出现对应滑块；
- 参数默认值：最小值 −10，最大值 10，默认值 1，步长 0.1；
- **同一个参数在多个函数间共享**：例如同时添加 `y=a*x` 与 `y=a*x^2`，拖动同一个 `a` 滑块，两个函数的图像同时变化；
- 最多 **10 个参数**。

以下内容不会被识别为参数：`x`、`e`、`pi`、函数名（sin、cos、sqrt、log 等）。

### 8.2 使用滑块

- 拖动滑块，函数图像**实时刷新**；
- 右侧面板的性质分析同步更新；
- 已开启的导函数、切线与割线也实时更新。

### 8.3 其他操作

- **全部重置为 1**：将所有参数值恢复为默认值 1；
- **参数自动清理**：删除某个函数时，若某个参数只被该函数使用，该参数会随函数一并删除；多个函数共享的参数会保留。编辑表达式导致参数不再被使用时也会自动清理。

> 典型演示：添加 `y=a*x^2+b*x+c`，把 `a` 从 1 调到 −1，观察抛物线开口方向翻转；调整 `c` 观察图像上下平移。

## 九、底部面板 · 计算器

用于进行数值计算，使用 math.js 引擎。

### 9.1 使用方法

1. 输入计算式，例如 `sin(pi/2)`；
2. 按回车或点击「**计算**」；
3. 下方显示输入、公式预览、结果与近似值；
4. 每次计算自动加入右侧「历史记录」。

### 9.2 支持的计算

- 四则运算：`2+3*4`、`(5+3)/2`
- 乘方：`2^10`
- 平方根：`sqrt(16)`
- 绝对值：`abs(-5)`
- 三角函数：`sin(pi/2)`、`cos(pi)`、`tan(pi/4)`
- 反三角函数：`asin(1)`、`acos(0)`
- 指数与对数：`exp(1)`、`log(10)`（自然对数）、`log10(100)`（常用对数）
- 常数：`pi`、`e`

### 9.3 限制

- 计算器**不支持变量**（如 `x+2` 会被提示“计算器不支持变量”）；
- 复数的乘方结果会以复数形式显示；
- 除零等未定义结果提示“无定义”。

## 十、底部面板 · 方程求解

支持分步求解并自动验证结果。

### 10.1 一元一次方程

1. 选择「一元一次方程」；
2. 输入如 `2*x+3=7`；
3. 点击「分步求解」；
4. 展示步骤：写出原方程 → 移项并合并 → 系数化为 1 → 代入验证，得到 `x = 2`。

更多示例：`5*x-2=3*x+6`。

### 10.2 一元二次方程

1. 选择「一元二次方程」；
2. 输入如 `x^2-5*x+6=0`；
3. 求解过程展示：标准形式 → 系数 a/b/c → 判别式 → 根的数量 → 求根公式（判别式为完全平方数时附带因式分解）→ 代入验证。

更多示例：`2*x^2+3*x-2=0`。

### 10.3 一元一次不等式

1. 选择「一元一次不等式」；
2. 输入如 `2*x+3>7`；
3. 求解过程自动处理**除以负数时不等号方向改变**，例如 `-2*x+4>0` 的解集为 `x < 2`。

支持运算符：`>`、`<`、`>=`、`<=`。更多示例：`3*x-1<=8`。

### 10.4 解题记录

- 每次求解自动存入右侧「解题记录」；
- 可一键「清空记录」。

> 初版不实现复杂分式不等式与高次不等式，此类输入会给出明确提示。

| 点 | 名称、X、Y | 点 A：X=2，Y=3 |

| 圆 | 圆心、半径、面积、周长 |

### 11.3 平移与编辑方程

- **整体平移**：选中对象后，使用左侧「平移」工具在画布上拖动，对象整体移动，距离/中点/斜率/面积/周长与方程自动更新；
- **修改方程**：选中对象后，在右侧属性面板「方程」输入框中修改并点「更新」，几何对象随之改变（支持直线 `y = kx + b`、`x = c` 与圆 `(x-a)^2+(y-b)^2=r^2` 形式）。

### 11.4 列表操作

- 每个对象可**隐藏/显示**、**删除**；
- 点击对象在画布上选中，可在右侧属性面板查看与编辑。

> 示例：点 A(2,3)、点 B(6,5) → 线段 AB 长度为 √20 ≈ 4.4721，中点为 (4,4)，斜率为 0.5。
> 不实现自动几何证明与图片识别。

## 十三、底部面板 · 导数分析

用于入门级导数可视化。**首先在「表达式」面板对某个函数点击「显示导数」。**

### 13.1 开启导数分析

在「表达式」面板点击函数条目上的「显示导数」：

1. 画布出现该函数的**导函数**（紫色虚线）；
2. 出现曲线上可拖动的**切点 P**、**切线**（红色虚线）、**割线**（橙色）与点 Q；
3. 出现**临界点**“×”标记；
4. 底部「导数分析」面板同步显示详细内容。

再次点击「隐藏导数」即可关闭。

### 13.2 求导方式与结果

- **符号求导**：支持 `x`、`x^2`、`x^3`、`2*x^2+3*x-1`、`sin(x)`、`cos(x)`、`exp(x)`、`log(x)` 等；
- **数值导数**：对无法符号求导的表达式自动切换为数值近似，页面会明确标注；
- 面板展示求导的**分步过程**，点击「**数值验证导数**」可用数值方法核对结果。

例如 `f(x)=x^2`：符号求导结果为 `f'(x)=2*x`，验证通过。

### 13.3 切线动态展示

- 直接**拖动画布上的点 P**，或在该面板输入「切点横坐标 a」；
- 实时显示：当前点 P(a, f(a))、导数值 f'(a)、切线斜率、切线方程；
- 切线方程采用 `y - f(a) = f'(a)(x - a)` 形式，也显示为 `y = kx + b`。

示例：`f(x)=x^2`，`a=2` 时显示：

```
当前点：P(2,4)
导数值：f'(2)=4
切线斜率：4
切线方程：y=4x-4
```

### 13.4 割线逼近切线

- 拖动「步长 h」滑块（范围 0.01 ~ 5，默认 2）；
- 点 Q(a+h, f(a+h)) 随 h 变化，割线斜率 `k_h = [f(a+h)-f(a)]/h`；
- h 越小，割线越接近切线，斜率差值 `|k_h − k|` 越小；
- 该功能直观展示导数的几何意义（不要求严格极限证明）。

### 13.5 显示内容控制

「导数分析」面板顶部提供「显示内容」开关，可独立显示/隐藏各可视化元素：

| 按钮 | 作用 |
| --- | --- |
| 原函数 | 显示/隐藏原函数曲线（等价于表达式列表的显示/隐藏） |
| 导函数 | 显示/隐藏紫色虚线导函数曲线 |
| 切线 | 显示/隐藏切线及其端点 P（隐藏时割线一并隐藏） |
| 割线 | 显示/隐藏橙色割线与点 Q |
| 临界点 | 显示/隐藏“×”临界点标记 |

高亮（蓝底）表示当前显示，点击可切换。适合单独观察某条曲线或对比原函数与导函数。

### 13.6 单调性与极值

- 自动分析单调区间与临界点，例如 `f(x)=x^2-4*x+3`：
  - `f'(x)=2*x-4`，令其等于 0 得 `x=2`；
  - 区间 `(-∞,2)` 递减、`(2,+∞)` 递增，`x=2` 为极小值点；
- 在右侧属性面板打开「**显示单调性提示**」，画布上会标注递增/递减箭头与临界点坐标；
- 对一般函数进行数值搜索时使用谨慎表述：`数值分析发现可能的临界点。`（不作为严格数学证明）。

## 十四、典型学习场景示例

### 场景一：探索一次函数参数（斜率与截距）

1. 表达式面板输入 `y=a*x+b`；
2. 参数面板拖动 `a`，观察直线倾斜程度变化；拖动 `b`，观察直线上下平移；
3. 选中该函数，右侧展示斜率、y 轴截距、与 x 轴交点与单调性。

### 场景二：研究二次函数顶点与根

1. 输入 `y=a*x^2+b*x+c`；
2. 设置 `a=1、b=-4、c=3`；
3. 右侧显示对称轴 `x=2`、顶点 `(2,-1)`、判别式 `Δ=4`、与 x 轴交点 `x=3,1`；
4. 改变 `a` 的正负观察开口方向。

### 场景三：理解导数的几何意义

1. 输入 `f(x)=x^2` 并「显示导数」；
2. 拖动点 P 到 a=2，观察切线 `y=4x-4`；
3. 调节割线步长 h，观察割线斜率逐步逼近 4；
4. 观察原函数在 x>0 递增时导函数为正。

### 场景四：一元二次方程分步求解

1. 进入「方程求解」选「一元二次方程」；
2. 输入 `x^2-5*x+6=0`，查看判别式与因式分解过程；
3. 用计算器验证：`2*3-5*3+6=0`。

### 场景五：几何与统计综合练习

1. 几何面板添加点 A(2,3)、点 B(6,5) 与圆 O(0,0) 半径 3；
2. 统计面板输入 `12,15,15,18,20`，查看平均数 16、中位数 15、众数 15；
3. 切换柱状图/折线图观察频数分布。

### 场景六：平移函数并生成解析式

1. 输入 `y=x^2`；
2. 使用左侧「平移」工具把抛物线向右拖动 2 个单位、向上 3 个单位；
3. 右侧「图像平移」区自动显示方向描述“向右平移 2 个单位，向上平移 3 个单位”与解析式 `(x - 2)^2 + 3`；
4. 点击「应用为新函数」把平移后的解析式加入列表，或「复制解析式」。

### 场景七：画布绘制几何并修改方程

1. 使用「圆」工具在画布上点击圆心与圆周点画一个圆；
2. 使用「平移」工具拖动该圆，观察半径、面积与方程实时更新；
3. 选中该圆，在右侧「方程」输入框改为 `(x-1)^2+(y-2)^2=16` 并点「更新」，圆心与半径随之改变。

### 场景八：选取函数关键点

1. 输入 `y=x^2` 并开启导数；
2. 点击曲线上的几个位置选取点，右下角「已选取的点」显示各点坐标、函数值与导数值；
3. 拖动某个取点标记沿曲线移动，观察函数值变化；用「×」或「清空」整理。

- 本工具不承诺解决所有数学问题，不支持的内容会明确提示：`当前版本暂不支持该数学内容。`

## 十七、常见问题 FAQ

**Q1：为什么输入 `1/x` 在 x=0 附近没有连线？**
A：这是正确的间断点处理。函数在 x=0 处无定义，画布不会把两侧错误连接。

**Q2：为什么 `sin(pi/2)` 在计算器中结果正常，但在表达式面板输入后没反应？**
A：表达式面板用于绘制函数图像（含自变量 x）。纯数值计算请使用「计算器」面板。

**Q3：在表达式面板输入 `2*x+3=7` 为什么画了一条水平线？**
A：函数画布自动提取等号右侧表达式，`2*x+3=7` 被当作 `y=7` 绘制。解方程请使用「方程求解」面板。

**Q4：参数滑块为什么没有出现？**
A：只有表达式中包含 `a、b、c、k、A、w、p` 等**非保留符号**才会生成滑块。`x`、`e`、`pi` 和函数名不算参数。

**Q5：导数分析显示“已切换为数值导数”是什么意思？**
A：该表达式暂不支持完整符号求导，系统改用中心差分 `f'(x) ≈ [f(x+h)-f(x-h)]/(2h)` 做数值近似（h=0.0001），并在页面明确标注“数值近似”。

**Q6：为什么撤销没有恢复我拖动参数的变化？**
A：拖动滑块属于连续操作，为避免历史记录爆炸不计入撤销历史。撤销/重做针对的是添加/删除/编辑函数、几何对象等结构性修改。

**Q7：换了浏览器或电脑，画布内容还在吗？**
A：localStorage 只保存在当前浏览器。跨设备迁移请使用「导出 JSON / 导入 JSON」。

**Q8：手机/窄屏上能用吗？**
A：初版为桌面端优先，宽度低于 1024px 会提示“数学画布初版建议在桌面端使用”。请使用电脑浏览器访问。

**Q9：符号求导支持哪些函数？**
A：初版支持常数、幂函数（整数次幂）、常数倍、和与差，以及 `sin`、`cos`、`exp`、`log`。其他函数会降级为数值导数。

**Q10：为什么有些函数不能完整分析性质？**
A：对于无法识别为一次/二次/反比例/三角函数的复杂函数，系统会显示“当前版本暂不支持该函数的完整性质分析”。

**Q11：为什么滚轮不再缩放画布了？**
A：滚轮改为**调整画布比例**（上滚增大宽高比、下滚减小）。缩放请使用画布右上角的 ＋/− 按钮或「适配」。

**Q12：「选择」和「拖动」有什么不同？**
A：「选择」只用于选中对象（点击曲线取点、选中几何图形），不会平移画布；「拖动」只用于平移画布视野。需要移动画布时请先切换到「拖动」工具。

**Q13：如何整体平移一个几何图形？**
A：选中该对象后，使用左侧「平移」工具在画布上按住拖动即可；平移后距离/中点/面积/周长与方程会自动更新。

**Q14：画出的圆为什么是椭圆？**
A：正常情况下画布默认为 1:1 正方形、单位长度一致，圆始终是正圆。若选择「自适应」等非正方形比例，画布仍保持单位长度一致、圆仍是正圆；如发现明显变形，请点右上角「1:1」按钮恢复。

# 路线图

## 当前版本（v0.1.0 · 初版）

- [x] 中学数学核心功能（约 80%）：函数画布、表达式、参数、性质分析、计算器、方程与不等式、几何、统计
- [x] 导数入门功能（约 20%）：符号求导、数值导数、切线、割线逼近、单调性与极值
- [x] 本地保存、撤销/重做、JSON 导入导出、错误边界
- [x] 模块化学科架构预留

## 近期（v0.2）

- [ ] 表达式输入增强：MathLive 输入适配层、更多输入容错提示
- [ ] 函数画布：自定义定义域、交点/零点自动标注
- [ ] 方程：可含参数的一元方程求解（利用共享参数滑块）
- [ ] 统计：频数分布直方图分组功能
- [ ] 示例库与练习题集

## 中期（v0.3）

- [ ] 高等数学（`calculus`）：极限入门、一元函数微积分、定积分可视化
- [ ] 导数增强：积/商/链式法则正式开放、高阶导数
- [ ] 函数变换：平移、伸缩、对称的交互演示

## 远期（v1.x）

- [ ] 线性代数：矩阵、线性方程组、行列式、线性变换与二维可视化
- [ ] 概率论：概率计算、随机变量、常见概率分布与直方图拟合
- [ ] 复变函数：复数运算、复变函数与基本映射
- [ ] 用户自定义主题与国际化（中/英）

## 原则

- 每个新学科以独立的 `SubjectModule` 接入，不重构现有架构；
- 未开放的学科不提前提供虚假计算逻辑；
- 保持简单、稳定、可运行，优先教学价值而非功能数量。
